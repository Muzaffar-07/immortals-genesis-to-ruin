# Immortals: Nightfall — Windows PC alpha

The first downloadable Godot edition of **Immortals: Genesis to Ruin**.

Download **Immortals-Nightfall-Windows-x64.zip**, extract the entire folder, and
run **Immortals.exe**. Keep the `.pck` file beside the executable. The game runs
offline without an account or installation. For older graphics hardware, use
**Launch-Compatibility.cmd**.

- Select Aro or Ena, original textured and rigged human-like alien protagonists.
- Play six compact missions from the first forest to the end of creation.
- Third-person movement, sprint, dodge, energy strikes, and Communion healing.
- Scanned PBR environmental assets, Full HD rendering, fog, shadows and particles.
- Recorded positional footsteps and impacts, optional blood, mission journal,
  chapter checkpoints, and three difficulty settings.

**Controls:** WASD move, mouse look, left click strike, Shift sprint, Space dodge,
E interact, F Communion, M journal, Escape pause.

This is an early independent PC alpha. It has repeated arena props, limited
animation and enemy variety, and no dialogue, controller support, multiplayer,
or console release. It is not a finished photorealistic AAA game. The executable
is unsigned. A PlayStation 5 release has not been produced.

Validation: all six mission completion paths with both characters; health,
sanctuary and timeout failure paths; movement, aim, dodge, healing, pause/resume;
Full HD rendering checks on a GTX 1650 Ti. Assisted tests do not establish balance.

Game code is MIT licensed. Assets and engine notices are included. Original
character assets were generated with Higgsfield (Tripo/Meshy). Environment scans
are CC0 from Poly Haven; recordings are CC0 from Kenney.

The source is in `native/`. Import `native/project.godot` with Godot 4.7.2 to edit
or build it. The browser prototype remains available at
https://immortals-genesis-to-ruin.vercel.app.
